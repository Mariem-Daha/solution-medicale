Solution Médicale

L'application des médecins de la clinique : consultations, ordonnances, hospitalisations, rendez-vous et bons, sur le téléphone, par le Wi-Fi de la clinique.

Commencer

  1. Sur le PC de la clinique, ouvrez le Dossier Médical : menu Téléphones → Lier un téléphone.
  2. Connectez le téléphone au Wi-Fi de la clinique.
  3. Dans l'application, touchez Scanner le QR code, puis choisissez votre code à 4 chiffres.

Pour essayer sans clinique : Découvrir l'application sur le premier écran (patients fictifs), et la clinique de démonstration pour la liaison, le code et l'empreinte.

Questions fréquentes

  • « Serveur de la clinique injoignable » : vérifiez que le téléphone est sur le Wi-Fi de la clinique.
  • Code oublié : après 5 essais, le téléphone se délie ; liez-le de nouveau depuis le Dossier Médical.
  • Téléphone perdu : la clinique le retire dans le Dossier Médical (menu Téléphones) ; il perd aussitôt l'accès.
  • Dictée : elle fonctionne sans internet ; sur iPhone, la dictée en français doit être activée (Réglages › Général › Clavier).
